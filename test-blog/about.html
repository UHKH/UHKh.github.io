关于本站 ​

这是一个测试站点，用来验证用 VitePress 写作并发布的完整流程。

技术栈 ​

  • VitePress —— 静态站点生成器，Markdown 进，HTML 出
  • Vite —— 开发服务器与打包
  • Node.js —— 运行构建脚本

目录结构 ​

text
test-blog/
├─ docs/                    # 站点根目录
│  ├─ .vitepress/
│  │  └─ config.mts         # 站点配置（导航、侧边栏、base）
│  ├─ posts/
│  │  └─ test-post.md       # 测试博文
│  ├─ about.md              # 本页
│  └─ index.md              # 首页
├─ package.json
└─ README.md

常用命令 ​

命令作用
npm run docs:dev启动开发服务器，改完即刷新
npm run docs:build构建静态站点
npm run docs:preview预览构建产物
